# MacDiskMonitor

A macOS disk-space monitor with circular storage indicators and desktop widgets.
It shows connected drives and SD cards, with Small, Medium, Large and Extra Large widgets.

## Beta 1 downloads

**Requires macOS 26.0 or later.** Intel Macs must support macOS 26.

- [Apple Silicon — M1, M2, M3, M4, M5](https://github.com/papobocabox-ui/MacDiskMonitor-Downloads/releases/download/v1.0.0-beta.1/DiskMonitorWidget-Beta-ARM64.dmg)
- [Intel Mac](https://github.com/papobocabox-ui/MacDiskMonitor-Downloads/releases/download/v1.0.0-beta.1/DiskMonitorWidget-Beta-Intel.dmg)
- [Installation instructions](https://github.com/papobocabox-ui/MacDiskMonitor-Downloads/releases/download/v1.0.0-beta.1/README-Installation.txt)
- [Beta 1 release page](https://github.com/papobocabox-ui/MacDiskMonitor-Downloads/releases/tag/v1.0.0-beta.1)

Open the DMG and drag MacDiskMonitor into Applications. Launch the app once,
then use the desktop's Edit Widgets menu to add a Mac Disk Monitor widget.

## Security notice

**This beta is not notarized by Apple. Gatekeeper may block it.**
If you trust this download and macOS offers the option, go to
**System Settings → Privacy & Security → Open Anyway** to approve this specific app.
Do not disable Gatekeeper globally. If the option is unavailable or the app still
will not open, stop and report the exact error to the developer.

This is an experimental pre-release. Widget refresh timing is controlled by macOS.
Physical Intel hardware and clean-machine widget behavior have not yet been fully tested.
For diagnostics, choose Help → Export Diagnostics… in the app.

This repository contains download information only. No application source code is included.
